## Resources

Collecting rate = a·D / (1 + a·D·h), Holling's disc equation: a = speed × sweep width (hectares searched per hour), D = units per hectare, h = handling time per unit. A place is 20 ha. "Limited by" says which term dominates at full abundance: search (scarce things) or handling (common things).
